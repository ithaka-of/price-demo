# price-demo

Демонстрационные страницы прайс-листов: поиск по позиции и заявка списком
вместо переписки с менеджером.

Каждая страница собрана из открытого прайс-листа компании, опубликованного на её
собственном сайте. Данные не изменяются: цены, параметры и номера страниц
переносятся построчно. Страницы не являются офертой и не связаны с сайтами
компаний, о чём сказано в шапке каждой из них.

| Папка | Компания | Источник |
|---|---|---|
| `mmk/` | ОАО «ММК-МЕТИЗ» | прайс-лист с 01.09.2026, `mmk-metiz.ru` |
